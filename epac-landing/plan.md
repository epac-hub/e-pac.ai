# e-pac.ai — conservar y mejorar la portada espacial

El usuario confirmó el 10-19-2026: «Conserva y mejora la portada espacial de e-pac.ai». La fuente aprobada es el index.html público del commit fcfc9503d9b79f69fac82ac528121374eff56c11, conservado en design-notes/space-original/index.html. Se mantiene pantalla única negra, estrellas hacia la cámara, logo ePAC. centrado dentro del círculo, entrada cinematográfica y copyright discreto. No volver a Culebra, casas, videos costeros, nuevas secciones ni scrolling.

Mejoras consolidadas: escena verdaderamente 3D en tiempo real con Three.js, profundidad/perspectiva, movimiento frontal independiente de fps, estrellas puntuales y estelas discretas cercanas, parallax sutil al puntero y resolución adaptativa; fallback 2D y escena estática cuando se pausa/reduced motion. Logo existente ePAC. en el estilo serif original, conservando letras, punto, círculo, blanco/negro y proporciones. Se restaura únicamente la nitidez del PNG si la edición preserva esos elementos; el original se mantiene como respaldo. Entrada más breve para no dejar el logo borroso varios segundos; nada de nuevos slogans o texto comercial visible.

Se preserva el audio espacial existente. La interfaz sigue casi invisible: controles pequeños de audio y pausa, accesibles por teclado, sin barras o paneles nuevos. El audio requiere activación explícita; no arranca por tocar cualquier elemento. La escena pausa cuando la pestaña no está visible y se libera al desmontar. Logo y footer son HTML estático accesible aunque no haya WebGL/JavaScript.

## Estructura
src/App.tsx: composición aprobada y entrada; src/components/StarFlight.tsx: escena 3D y fallback; src/styles.css: pantalla negra, logo central y controles; public/brand: original y restauración validada; public/media/space-ambient.mp3: audio existente; tools: verificación de movimiento/layout y publicación. React/Vite/TypeScript y Three.js ya instalados, sin backend, base de datos ni servicios nuevos.

Se publica la mejora en https://e-pac.ai mediante la configuración existente de GitHub Pages, preservando CNAME, 404.html, assets originales, archivos históricos y cambios remotos. El Preview debe coincidir con el destino público; no se sustituye el dominio por un túnel temporal. Se documenta QA sin afirmar rendimiento/4K/fotorealismo que no se haya medido. Se reporta la hora de Puerto Rico cada cinco minutos mientras el trabajo esté activo; no se crea una automatización indefinida ajena al sitio.
